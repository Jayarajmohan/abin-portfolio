# Abin Remanan — Cinematic Portfolio

Next.js (Pages Router, JavaScript) · Tailwind CSS v4 · GSAP + ScrollTrigger · Lenis · Motion · React Hook Form · Resend

The homepage is an animated short film played by scrolling: one full-screen video, scrubbed
forwards and backwards by a single GSAP timeline, with the text, skills, projects and contact
form laid over the dark right side of each shot.

## Run locally

```bash
npm install
cp .env.example .env.local   # fill in RESEND_API_KEY and CONTACT_TO_EMAIL
npm run dev                  # http://localhost:3000
```

## Editing content

All content lives in `src/data/`:

| File | What it holds |
|---|---|
| `site.js` | Name, role, intro line, email, socials, showreel, software |
| `story.js` | Copy for every scene, skills-as-timeline-clips, experience highlights |
| `projects.js` | Selected works (horizontal gallery) + `/work/[slug]` case-study pages |
| `experience.js` | Roles shown in Scene 04 |
| `film.json` | Generated by `npm run film` — don't edit by hand |

## The film

Source files live in `assets-src/film/`:

- `shot-1.mp4` … `shot-6.mp4` — the six Flow shots, one per scene, each starting on the
  previous shot's last frame
- `k0.jpg` … `k6.jpg` — the keyframes the shots were generated between

`npm run film` joins the shots into `public/film/film.mp4` (encoded for scroll-scrubbing:
keyframe every 6 frames, no B-frames), crops off the generator watermark, exports the
keyframes as `public/film/k*.webp`, and writes timings to `src/data/film.json`.

To replace a shot: overwrite `assets-src/film/shot-N.mp4` and run `npm run film`.

**Phones** get `public/film/film-portrait.mp4` (9:16). Each shot *plays* when its scene
scrolls into view and holds its last frame (phones play video smoothly but seek poorly);
desktop scrubs frame by frame. If native vertical shots exist in `assets-src/film/mobile/`
(`k0…k6` + `shot-1…6.mp4`), `npm run film` builds the phone film and stills from them;
otherwise it crops the landscape shots to follow Abin.
If Abin sits somewhere else in the new shot, update its `FOCUS` entry in
`scripts/build-film.cjs` (used to keep him in view on portrait phones).

## How the animation is built

```
src/components/story/
  StoryExperience.js  sticky stage + flow column; builds the timeline (gsap.matchMedia)
  timeline.js         the master timeline — CUTS maps shots to scenes; all text choreography
  Film.js             the <video> + keyframe stills (loading / reduced-motion fallback)
  filmPlayer.js       loads the film into memory and seeks it smoothly
  Scenes.js           stage overlays: intro, edit suite, skills timeline, experience
  Particles.js        lightweight canvas dust
  WorksScene.js       horizontal scrubbed gallery + video lightbox
  ContactScene.js     final scene + form
```

- Timeline time = pixels scrolled, so `at("skills", 0.5)` means "halfway through the Skills scene".
  To give a scene more or less scroll, change its height in `StoryExperience.js` (e.g. `h-[280svh]`).
- Reduced motion: no video; the keyframe stills cross-fade between scenes.
- Lenis is driven by GSAP's ticker so smooth scrolling and ScrollTrigger stay in sync.

## Deploy (Vercel)

Set `RESEND_API_KEY`, `CONTACT_TO_EMAIL`, `CONTACT_FROM_EMAIL` (address on a domain verified in Resend)
and `SITE_URL`. Also set `site.url` in `src/data/site.js` to the production domain.
